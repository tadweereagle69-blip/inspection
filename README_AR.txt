نظام التفتيش الميداني - ULTIMATE v20 Smart Voice

تحسين تجربة الصوت بدون تغيير بقية النظام:
- ميكروفون واحد داخل خانة النص.
- أثناء التسجيل يتحول نفس الزر إلى إيقاف (■).
- يظهر: 🔴 جاري الاستماع... + عداد زمني.
- إيقاف تلقائي بعد قرابة 5 ثوانٍ من السكوت.
- الكلام الجديد يُضاف إلى النص الموجود، ولا يحذفه.
- أوامر صوتية عربية:
  نقطة، فاصلة، فاصلة منقوطة، علامة استفهام، علامة تعجب، سطر جديد، فقرة جديدة، نقطتان.
- تمييز بصري لحظي بعد إضافة الكلام.
- ✨ تحسين النص يظهر فقط عند وجود نص.
- ↩ تراجع يظهر فقط عندما توجد عملية يمكن التراجع عنها.
- قاموس محلي محافظ لبعض مصطلحات التفتيش وPPE.
- حذف التكرار الواضح الناتج عن التعرف على الصوت.
- إذا كان المتصفح لا يدعم SpeechRecognition يختفي زر الميكروفون بالكامل، والكتابة اليدوية تبقى طبيعية.
- لا يوجد API مدفوع ولا مفتاح خارجي.
- كل وظائف ULTIMATE v18/v19 الأخرى بقيت كما هي.
