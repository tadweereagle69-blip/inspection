نظام التفتيش الميداني - ULTIMATE v19 Voice

إضافة فقط بدون تغيير وظائف النظام:
- 🎤 تحدث: تحويل الكلام العربي إلى نص في:
  * ملخص الزيارة
  * وصف الحالة / الملاحظة
  * الإجراء التصحيحي
  * ملاحظة المتابعة
- أثناء الاستماع: 🔴 جاري الاستماع... + زر إيقاف.
- الكلام الجديد يُضاف إلى النص الموجود ولا يحذفه.
- ✓ تصحيح: تنظيف محلي محافظ للنص (تكرار الكلمات، المسافات، علامات الترقيم وبعض الأخطاء العربية البسيطة).
- ↩ تراجع: يرجع إلى النص السابق قبل التحدث أو التصحيح.
- لا يوجد API key أو اشتراك مدفوع.
- في المتصفح غير الداعم: الكتابة اليدوية تعمل طبيعيًا، وزر التحدث يكون معطلاً.
- تم الحفاظ على جميع وظائف v18 كما هي: Toggles، N/A، الصور، التوقيع، PDF، المشاركة، السجل، التعديل والمسودة.
