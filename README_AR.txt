نظام التفتيش الميداني — النسخة النهائية v13

أنواع التفتيش:
- ميداني (يشمل المركبات والمعدات والمبيدات وPPE وتنفيذ العمل)
- السكنات
- المكتب
- المستودع / الورشة / المختبر
- أخرى

المنطق:
- الفئة نفسها فقط: مطابق / غير مطابق / لا ينطبق.
- لا توجد بنود فرعية داخل الفئة.
- عند غير مطابق يكتب المفتش الحالة بنفسه ويمكن إضافة أكثر من حالة.
- يلزم صورتان توثيقيتان على الأقل لإثبات الزيارة قبل إنهاء التقرير.
- يلزم توقيع المفتش.
- التقرير يدعم المعاينة كصورة والمشاركة وPDF والطباعة.
- السجل يدعم الفتح والتعديل والمتابعة والحذف والبحث.
- النظام عام وغير مرتبط بقطاع أو مشروع محدد.
